# Agent logos

Official logo files for AI agents go here, named by id:

| File | Agent |
|---|---|
| `claude.svg` / `claude.png` | Claude (Claude Code, Claude Desktop) |
| `codex.svg` | Codex |
| `antigravity.svg` | Antigravity CLI |
| `gemini.svg` | Gemini CLI |
| `cursor.svg` | Cursor |
| `vscode.svg`, `windsurf.svg`, `lm_studio.svg` | Those apps |

Use the files each company publishes for partners (press or brand kits) and follow their brand guidelines. A file here is used everywhere TodoCity shows that agent. Without one, TodoCity shows the icon of the app installed on the Mac, or a lettered tile.
